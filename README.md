# Framework de Programación Web

Repositorio con las prácticas de la asignatura **Framework de Programación Web** (UPSE - 7.º semestre).

## Contenido

| Carpeta | Descripción |
|---------|-------------|
| `Practica 01/` | Práctica 01 |
| `Practica_02/` | Interfaz en React + TypeScript + Vite consumiendo la PokeAPI (151 pokémon) |
| `Practica_03/` | Práctica 03 |

## Cómo levantar una práctica en local

Cada práctica es un proyecto independiente. Entra a su carpeta e instala dependencias:

```bash
cd "Practica_02"
npm install
npm run dev
```

Luego abre la URL que muestra Vite (por defecto `http://localhost:5173`).
